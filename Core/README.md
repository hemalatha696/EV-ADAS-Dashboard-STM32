# Core

This folder contains the main application source code for the **EV Dashboard & ADAS Warning System** developed using the STM32F103C8T6 (Blue Pill).

## Folder Structure

```
Core/
├── Inc/       # Header files
├── Src/       # Source files
└── startup/   # Startup assembly and system initialization files
```

## Description

The Core folder includes all application-specific firmware responsible for:

- EV Dashboard logic
- ADAS warning system
- ADC sensor acquisition
- GPIO control
- UART communication
- Timer configuration
- Ultrasonic sensor processing
- Fault detection
- Buzzer and LED control

## Features

- Real-time EV Dashboard
- Advanced Driver Assistance System (ADAS)
- UART Telemetry
- ADC Sensor Reading
- GPIO Control
- Timer Interrupts
- Ultrasonic Distance Measurement
- Collision Warning System
- Fault Monitoring

## Development Environment

- STM32CubeIDE
- Embedded C
- STM32 HAL Library
- STM32F103C8T6 (Blue Pill)
- PICSimLab
