# Src

This folder contains the Embedded C source files for the EV Dashboard & ADAS project.

## Contents

- main.c – Main application entry point
- gpio.c – GPIO configuration and control
- adc.c – ADC initialization and sensor reading
- tim.c – Timer configuration
- usart.c – UART communication
- ev_control.c – EV dashboard logic
- adas.c – ADAS warning system
- ultrasonic.c – Ultrasonic sensor interface
- buzzer.c – Buzzer control
- fault.c – Fault detection and handling

## Features

- Real-time EV Dashboard
- ADAS Collision Warning
- UART Telemetry
- Sensor Data Processing
- Fault Monitoring
- Embedded C Firmware
