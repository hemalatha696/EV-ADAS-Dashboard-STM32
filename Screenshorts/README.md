# Screenshots

This folder contains screenshots of the **EV Dashboard & ADAS Warning System** project developed during my Embedded Systems Internship.

## Contents

### 1. PICSimLab Connection
Shows the STM32 Blue Pill simulation setup, peripheral connections, and hardware configuration in PICSimLab.

### 2. Python Dashboard
Displays the real-time EV dashboard showing parameters such as Speed, State of Charge (SOC), Motor Temperature, Torque, and Range using UART communication.

### 3. Internship Certificate
Certificate of successful completion of the Embedded Systems Internship, demonstrating the completion of the EV Dashboard & ADAS project.

## Purpose

These screenshots provide a visual overview of the project implementation, simulation environment, and internship achievement.
