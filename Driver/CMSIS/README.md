# CMSIS

This folder contains the **Cortex Microcontroller Software Interface Standard (CMSIS)** files for the STM32F103C8T6 microcontroller.

## Purpose

CMSIS provides a standardized interface for ARM Cortex-M processors and enables portable software development across STM32 devices.

## Contents

- ARM Cortex-M3 core support
- Device header files
- Register definitions
- Interrupt and exception handling
- System initialization files

## Features

- Processor core access
- NVIC interrupt management
- System clock configuration
- Core register definitions
- Standard ARM software interface

## Target Device

- STM32F103C8T6 (Blue Pill)
- ARM Cortex-M3

## Development Environment

- STM32CubeIDE
- STM32 HAL Library
- Embedded C
